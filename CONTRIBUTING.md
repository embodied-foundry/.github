# Contributing

Applies to every embodied-foundry repo unless that repo's own CONTRIBUTING.md overrides it.

1. Branch from `main`.
2. Keep one concern per pull request.
3. If you change architecture or a contract, update the diagram and add or amend an ADR in [`architecture`](https://github.com/embodied-foundry/architecture) in a linked PR.
4. Open the PR, fill in the template, and request review.
5. A teammate who is not the author approves. Squash-merge once checks are green.

AI agents follow the same flow.
