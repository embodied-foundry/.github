# AGENTS.md

Instructions for AI coding agents working in this repo.

- Read [conventions/ai-agents.md](conventions/ai-agents.md) first. It applies here and in every other repo.
- Files here are org-wide defaults: a change affects every repo, so keep one concern per PR.
- A change to `rulesets/` or `conventions/` that alters process needs an ADR in the [`architecture`](https://github.com/embodied-foundry/architecture) repo.
- Docs describe the present. Put history and reasoning in ADRs and commit messages, not in the docs.
