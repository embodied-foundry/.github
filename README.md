# embodied-foundry

Org-wide process for every embodied-foundry repo: how we branch, commit, review and work with AI agents, and the GitHub rules that enforce it. The architecture, contracts, decisions and roadmap live in [`architecture`](https://github.com/embodied-foundry/architecture).

| Path | What lives there |
| --- | --- |
| [`conventions/`](conventions/) | Git workflow, GitHub rules, repo layout, AI-agent collaboration |
| [`rulesets/`](rulesets/) + [`scripts/`](scripts/) | GitHub rulesets as code and the script that applies them |
| [`CONTRIBUTING.md`](CONTRIBUTING.md), [`pull_request_template.md`](pull_request_template.md) | Contribution flow and PR template for every repo |
| [`profile/`](profile/) | Org profile page |

Changes land through pull requests reviewed by a teammate. See [CONTRIBUTING.md](CONTRIBUTING.md).
